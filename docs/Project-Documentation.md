# SWYNEX – Final Data Analytics Project

## 1. Introduction

This project focuses on analyzing the Titanic passenger dataset using data analytics techniques. It combines data cleaning, exploratory data analysis, statistical analysis, and interactive dashboard development.

## 2. Problem Statement

The Titanic dataset contains information about passengers, including age, gender, passenger class, fare, and survival status. The objective is to explore the dataset and identify patterns and factors associated with passenger survival.

## 3. Aim

To perform an end-to-end data analytics process and transform raw passenger data into meaningful insights through Python analysis and Power BI visualization.

## 4. Objectives

- Understand the dataset.
- Identify missing and duplicate values.
- Clean and preprocess the data.
- Perform exploratory data analysis.
- Analyze passenger survival patterns.
- Create meaningful visualizations.
- Develop an interactive Power BI dashboard.
- Present findings and conclusions.

## 5. Methodology

### 5.1 Data Collection
The Titanic dataset was used as the primary data source.

### 5.2 Data Cleaning
Missing values, duplicate records, and data inconsistencies were examined and handled.

### 5.3 Exploratory Data Analysis
Statistical analysis and visualizations were performed to understand the dataset and identify patterns.

### 5.4 Dashboard Development
Microsoft Power BI was used to create an interactive dashboard to present the analysis results.

## 6. Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Power BI
- GitHub

## 7. Expected Outcomes

- A cleaned and structured dataset.
- Statistical summaries.
- Exploratory data visualizations.
- An interactive Power BI dashboard.
- Meaningful findings about passenger survival.

## 8. Conclusion

This project demonstrates the complete data analytics workflow, including data preprocessing, exploratory analysis, visualization, and dashboard development. It provides practical experience in transforming raw data into useful information.
