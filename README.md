# SWYNEX – Final Data Analytics Project

## 1. Project Overview

This project presents an end-to-end data analytics case study using the Titanic dataset.

It combines data cleaning, exploratory data analysis (EDA), statistical analysis, data visualization, and an interactive Power BI dashboard to discover meaningful patterns in passenger survival.

## 2. Problem Statement

The Titanic dataset contains passenger information such as age, gender, passenger class, fare, and survival status.

The objective is to analyze this information to understand the factors associated with passenger survival and present the findings through meaningful visualizations and an interactive dashboard.

## 3. Project Objectives

- Understand and explore the Titanic dataset.
- Identify and handle missing and inconsistent data.
- Perform data cleaning and preprocessing.
- Conduct exploratory data analysis.
- Analyze survival patterns across passenger groups.
- Create meaningful visualizations.
- Develop an interactive Power BI dashboard.
- Present key findings and conclusions.

## 4. Dataset Information
